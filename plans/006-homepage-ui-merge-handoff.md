### R4 in detail — CTA instrumentation debt

`main`'s plan 004 requires every visible conversion-intent link to carry a stable CTA
id, and `CTA_IDS` in `lib/analytics/events.ts` is a **typed allowlist** — the server
rejects ids that are not in it, and an unlisted campaign slug silently buckets as direct
traffic. These new/changed surfaces have interactive elements that are not instrumented:

- `components/marketing/TeamScroller.tsx` — "Learn More" → `/contact`
- `components/marketing/WelcomeWalkModal.tsx` — "Book Now" handoff (its own comment notes
  there is no `lib/analytics` in this tree)
- `components/marketing/AlwaysIncluded.tsx` — icon buttons opening previews
- `components/booking/BookingOnboardingIntake.tsx` — onboarding entry

Decide per element whether it is conversion intent. If yes, add the id to `CTA_IDS` and
wire `TrackedCtaLink` / `TrackedCtaAnchor`. If no, leave it uninstrumented and say so —
a missing dashboard row must mean "not measured", never a false zero.
